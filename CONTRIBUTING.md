# Contribuir a SmartCaña

Este proyecto es parte de una tesis académica. Las contribuciones externas no están abiertas en esta etapa.

## Para desarrolladores del equipo

### Convenciones

- **Ramas:** `feature/nombre`, `fix/nombre`, `docs/nombre`
- **Commits:** Usar [Conventional Commits](https://www.conventionalcommits.org/)
  - `feat:` nueva funcionalidad
  - `fix:` corrección de bug
  - `docs:` cambios en documentación
  - `style:` formato, estilos
  - `refactor:` refactorización
  - `test:` tests
  - `chore:` tareas de mantenimiento
- **Code Review:** Toda incorporación requiere revisión

### Estándares

- TypeScript estricto
- Prettier para formateo
- ESLint para linting
- Tests unitarios para lógica de negocio
- Documentación para APIs y componentes públicos
